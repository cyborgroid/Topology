# QE Analog Topology

[Topology.md](Topology.md) 사양으로 만드는 **QE Analog Topology** — Digital OS 를 대신하는 Analog 화면.
화면은 실제 컴퓨터의 파일·앱·네트워크·시스템과 연결된다.

## 실행

| 스크립트 | 용도 |
| --- | --- |
| `./run.sh` | 로컬에서 띄우고 **접속 주소만 출력**한다. 그 주소를 VS Code 의 *Open Integrated Browser* 로 연다. Ctrl+C 로 종료. |
| `./vmware.sh` | VMware 게스트(Ubuntu 등)에서 **전체 화면 데스크톱 셸**로 실행한다. `--windowed` 창 모드, `--install` 앱 목록·자동 실행 등록. |

`run.sh` 는 의존성이 필요하다(`npm install`). 출력 주소의 `token` 은 실행할 때마다 새로 만들어지며,
토큰 없는 요청은 OS 연결(API)을 쓸 수 없다. 서버는 127.0.0.1 에서만 열린다.

`vmware.sh` 는 의존성이 없으면 설치하고, VMware 가상 GPU 에서는 소프트웨어 렌더링을 쓴다
(3D 가속을 켠 VM 에서 GPU 를 쓰려면 `TOPOLOGY_GPU=1 ./vmware.sh`).

## 두 가지 뷰 (작업 표시줄 또는 Tab 으로 전환)

### ◈ 양자 뉴런 블록 — 본 화면 (Quantum Neuron Block Computing)

**블록 = 기능을 맡은 단자(모듈).** 블록들을 호환되는 단자끼리 조립해 시스템을 구축한다.
**No Base = 초기 상태**: Topology 자체의 시스템 구조가 **보로노이 영역 개척**으로 완성된 채 시작하고, 거기서 블록을 더하거나 다시 이어 키운다
([src/field.js](src/field.js)).

- **영역 = 블록** — 블록마다 씨앗에서 자기 영역(다른 씨앗보다 자기에게 가까운 공간)을 개척하고, 그 영역 덩어리가 곧 양자 아날로그 뉴런 블록이다.
  영역들이 맞물려 물리(덩어리)와 수학(영역 분할) 사이에서 시스템 구조가 된다. 영역은 신호 순서대로 씨앗에서 자라난다.
  연결은 선이 아니라 두 영역이 맞닿는 접합면이 신호 색으로 빛나는 것이다. 영역 중심에 양자 뉴런 핵과 단자가 있다.
- **차원 D** (화면 위쪽 log 눈금 슬라이더, −10⁴ ~ 10⁴) — 크기 배수를 차원 지수로 계산한다: **N = (1/r)^D**, 차원은 log 로 잰다: **D = log N / log(1/r)** (N = 16).
  블록 씨앗은 신호 순서대로 초입방체의 그레이 코드 경로를 따라 놓이고, k 번째 영역의 선형 축척 λ = r^(k/(n−1)), 크기 배수 λ^D.
  - 0 < D ≤ 4: 초입방체 안의 프랙탈 — 상류가 넓은 영역을 개척하고 하류로 갈수록 좁아진다
  - D > 4: 4차원 너머 — r → 1, 영역들이 고르게 개척된다
  - D < 0: 음수 차원 — r > 1, 위계가 뒤집혀 하류(Topology)가 바깥의 큰 영역을 개척한다
  - D = 0: 모든 영역이 한 점으로 응축된다
- **폴더·파일도 블록** — 블록이 다루는 폴더(데이터 = 고른 폴더의 항목, 그 밖 = 개념에 접목된 폴더)가 블록 영역 안에서 같은 차원 법칙으로
  다시 영역을 개척한다(영역 안의 영역). 폴더 블록을 펼치면 그 안의 항목이 다시 그 안을 개척한다. 항목마다 양자 뉴런 하나(크기·항목 수가 입력).
- **양자 에너지 장** — 영역마다 그 블록의 신호 세기만큼 에너지 양자가 찬다. 영역 꼭짓점을 끌개로 한 프랙탈 먼지이고, 결은 차원에서 온다.
- **물리** ([src/physics.js](src/physics.js)) — 씨앗은 질량이다. 수학 자리로 당기는 용수철, 연결을 따라 이웃을 끄는 용수철, 너무 가까우면 밀어내는 힘(블록은 부피가 있어 겹치지 않는다).
  블록을 끌면 이어진 회로가 유기체처럼 따라오고, 놓은 자리는 저장된다. 차원을 바꾸면 회로가 물리로 새 자리에 옮겨 간다.
  질량 = 영역 부피 × 재료 밀도(무거운 블록은 덜 움직인다), 연결 강성 = 접촉면 넓이(넓게 맞닿을수록 단단하다).
- **조립** — 블록을 끌어 다른 블록에 맞대면, 맞닿은 면(보로노이 공유면)에 호환 단자가 있을 때 그 면으로 결합된다. 끄는 동안 결합할 수 있는 면이 빛난다.
  맞닿은 연결은 공유면 모양 그대로 **접촉 패드**, 떨어진 연결은 **브리지**(도체)로 보인다.
- **양자 코어 = 하나의 컴퓨터** (기본 형태) — 코어 하나가 모든 것을 품는다. 블록은 개념 블록과 실제 부품의 중간인 **모듈**이다:
  코어를 블록의 영역대로 나눈 조각이고, 조각들이 맞물려 26면 결정 외피의 코어 하나가 된다. 가운데 핵 영역에 **양자 핵**(QE 코어의 양자 뉴런 핵과 블로흐 구).
  모듈은 부품 쪽으로 다듬어져 있다([src/parts.js](src/parts.js)): 부품 번호(QM-01 …), 코어 바깥 면에 새겨진 **기능면**(메모리 셀 배열, 안테나 코일,
  차폐 격자, 포트 배열, 디스크 스택, 제어 커넥터 줄, 연산 다이·방열핀, 그래픽 다이·팬, 표시면 …), 가공한 부품 마감.
  연결된 두 모듈이 맞닿은 면에는 신호 규격의 **커넥터 하우징**(출력 쪽 수 커넥터 → 입력 쪽 암 커넥터: 양자 = 동축, 데이터 = 8핀 …),
  맞닿지 않은 연결은 핵 쪽으로 지나는 **내부 채널**.
  조립 상태는 카메라 쪽 1/8 을 잘라 낸 **절개도**로 안을, **⇱ 분해 보기**는 조각이 핵에서 떨어져 끼워지는 방식을 보여 준다.
  팔레트의 ◧ 형태 버튼: 양자 코어 → 수학(영역) → 큐브 조립안.
- **큐브 조립안** ([src/build.js](src/build.js)) — 영역을 한 변 20 mm 규격 큐브로 양자화한 조립 격자(이산 보로노이). 맞닿은 큐브 면 = 구리 패드, 커넥터 핀,
  맞닿지 않은 연결 = 큐브 사이 최단 배선.
- **조립 설계도** (팔레트의 ⚙ 조립 설계도) — 양자 코어 형태에서는 코어 외곽·부피·질량, 핵, **조립 순서**(핵부터 바깥으로, 단계마다 맞물리는 모듈),
  모듈(부품 번호·기능면·재료·부피·질량·수/암 커넥터 수), 결합부(커넥터 규격·위치·내부 채널 길이·지연). 큐브 조립안에서는: 부품표(재료별 큐브, 패드 면, 커넥터 핀, 도선 길이),
  층별 배치도와 조립 단계 슬라이더(아래층부터 쌓아 본다), 외곽 치수·부피·질량·무게중심, 블록별 큐브 수, 접합별 커넥터 위치·브리지 경로·컨덕턴스·지연.
  **💾 설계도 저장** 은 `~/.config/qe-analog-topology/core-design.json` 으로 남긴다(층별 큐브 좌표 포함).
  재료·큐브 크기 같은 가정값은 [src/topology.config.js](src/topology.config.js) 의 `PHYSICAL`.

| 묶음 | 블록 | 단자 (입력 → 출력) | 실제 환경 |
| --- | --- | --- | --- |
| 환경 | 데이터 | — → 데이터 | 고른 실제 폴더의 항목 수 |
| 환경 | 전화번호 · 계정 | — → 식별 | 이 컴퓨터의 계정 |
| 환경 | WIFI | — → 연결 | 지금 Wi-Fi 신호 세기 |
| 네트워크 | VPN | 연결, 데이터? → 연결 | VPN 인터페이스가 켜져 있는지 |
| 네트워크 | Network | 연결, 식별?, 데이터? → 연결 | |
| 네트워크 | 빅데이터 | 연결 → 데이터 | |
| 양자 · 처리 | QE 코어 | 데이터 → 양자 | |
| 양자 · 처리 | Instrument | 양자, 식별? → 명령 | |
| 양자 · 처리 | AI | 명령, 데이터? → 토큰 | |
| 양자 · 처리 | Graphic | 토큰 → 화면 | |
| 화면 | Topology | 화면, 명령? → — | 결과가 데스크톱 QE 시스템 창 · 작업 표시줄로 |

(`?` 는 비워 둬도 되는 단자)

- **호환** — 같은 신호 종류(같은 색) 단자끼리만 이어진다. 양자 신호는 복제할 수 없으므로 양자 출력은 한 곳에만 이어진다.
- **계산** — 조립이나 환경 값이 바뀔 때마다 시스템 전체를 신호 순서대로 계산한다. 양자 뉴런은 입력 세기를 큐비트 회전으로 싣고
  제어 회전으로 출력 큐비트를 움직여 1 이 될 확률을 낸다([src/blocks.js](src/blocks.js), [src/quantum.js](src/quantum.js)).
- **저장** — 조립한 시스템은 `~/.config/qe-analog-topology/program.json` 에 저장되어 다음에 이어서 쌓는다.

| 입력 | 동작 |
| --- | --- |
| 팔레트 클릭 · 판 위로 끌어다 놓기 | 블록 꺼내기 (경로의 다음 걸음에서 영역을 개척한다) |
| 차원 슬라이더 | 차원 D (log 눈금, 음수 ~ 4차원 너머) |
| 블록 드래그 | 끌어 옮기기 — 이어진 회로가 따라오고 놓은 자리가 저장된다 (패널의 ⟲ 수학 자리로). 맞대면 결합(조립) |
| 단자(핵 둘레 돌기) 드래그 | 잇기 (이을 수 있는 단자만 빛난다) |
| 빈 곳·Shift 드래그 / 오른쪽 드래그 | 회전 / 이동 |
| 블록 클릭 → 영역 안 클릭 · 더블클릭 | 폴더·파일 블록 고르기 · 폴더 펼치기/접기, 파일 열기 |
| 스크롤 | 다가가기 · 물러나기 |
| 클릭 · Delete | 영역·접합 선택(오른쪽 패널: 선형 축척 λ, 크기 배수 λ^D, 접합 끊기) · 지우기 |
| ↺ 초기 구조로 (No Base) | 결정체 초기 구조로 되돌리기 |

선택한 블록의 패널에서 Topology 환경으로 바로 간다: 데이터 → 폴더 층, WIFI·VPN·Network → 네트워크 창,
Instrument → 터미널, Topology → QE 시스템 창, 개념에 접목된 폴더.

### ▣ 데스크톱 — 깊이로 펼친 Digital OS

평소 2D 데스크톱과 같은 화면이 깊이 방향과 상하좌우로 이어진다.

- **스크롤** — 깊이(앞: 창 층 · 가운데: 바탕화면 · 뒤: 폴더 층). 멈추면 가장 가까운 층에 맞춰져 평소 화면 그대로 보인다.
- **마우스 끌기 · 화살표** — 한 층의 내용이 넘치면 페이지가 바둑판처럼 펼쳐진다. 빈 곳을 끌면 화면이 손을 따라오고,
  놓으면 가까운 페이지에 맞춰진다(1/5 이상 끌면 그 방향 다음 페이지).
- 폴더 클릭 = 뒤에 다음 층, 더블클릭 = 들어가기 / 파일 더블클릭 = 기본 앱. 폴더 탐색기 창은 없다.
- 바탕화면 아이콘: 양자 뉴런 블록, QE 시스템, 홈, 터미널.

## 구조

- [run.sh](run.sh), [server/server.js](server/server.js) — 로컬 서버(정적 파일 + 토큰 보호 API)
- [vmware.sh](vmware.sh), [app/main.js](app/main.js), [app/preload.js](app/preload.js) — Electron 전체 화면 셸
- [app/os-api.js](app/os-api.js) — 실제 OS 연결(파일, 앱, nmcli, 시스템 정보). 두 실행 방식이 함께 쓴다
- [src/bridge.js](src/bridge.js) — 화면 쪽 API (Electron 이면 preload, 아니면 토큰으로 서버 호출)
- [src/core.js](src/core.js) — 렌더러와 뷰 전환
- [src/diagram.js](src/diagram.js) — 양자 뉴런 블록 3D 조립판: 팔레트, 블록·단자·연결, 정보 패널, 마우스 조작
- [src/blocks.js](src/blocks.js) — 블록(기능 모듈) 정의, 호환 규칙, 시스템 계산(양자 뉴런)
- [src/field.js](src/field.js) — 차원(N = (1/r)^D, log 측정), 블록 씨앗(그레이 코드), 보로노이 영역 개척, 에너지 장
- [src/physics.js](src/physics.js) — 회로의 물리: 씨앗 질량(부피 × 밀도), 접촉 강성 용수철, 밀어내기, 감쇠
- [src/parts.js](src/parts.js) — 모듈의 기능면과 신호 규격 커넥터
- [src/build.js](src/build.js) — 큐브 조립안: 영역의 큐브 양자화, 패드 면, 브리지 배선 경로, 층
- [src/quantum.js](src/quantum.js) — 상태 벡터 시뮬레이터(H, Rx, Ry, CX, CRy, 블로흐 벡터)
- [src/desktop.js](src/desktop.js) — 데스크톱 뷰: 창 층 · 바탕화면 · 폴더 층, 스크롤 깊이 이동, 마우스로 상하좌우 페이지
- [src/taskbar.js](src/taskbar.js), [src/apps.js](src/apps.js) — 작업 표시줄·시작 메뉴, 내장 앱(터미널, 시스템, 네트워크, QE 시스템)
- [src/topology.config.js](src/topology.config.js) — 개념, 폴더 접목(ANCHORS), 조작 설정
