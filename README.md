# QE Analog Topology

[Topology.md](Topology.md) 사양으로 만드는 **QE Analog Topology** — Digital OS 를 대신하는 Analog 화면.
화면은 실제 컴퓨터의 파일·앱·네트워크·시스템과 연결된다.

## 실행

| 스크립트 | 용도 |
| --- | --- |
| `./run.sh` | 로컬에서 띄우고 **접속 주소만 출력**한다. 그 주소를 VS Code 의 *Open Integrated Browser* 로 연다. Ctrl+C 로 종료. |
| `./vmware.sh` | VMware 게스트(Ubuntu 등)에서 **전체 화면 데스크톱 셸**로 실행한다. `--windowed` 창 모드, `--install` 앱 목록·자동 실행 등록. |

`run.sh` 는 의존성이 필요하다(`npm install`). 출력 주소의 `token` 은 실행할 때마다 새로 만들어지며,
토큰 없는 요청은 OS 연결(API)을 쓸 수 없다. 서버는 127.0.0.1 에서만 열린다.

`vmware.sh` 는 의존성이 없으면 설치하고, VMware 가상 GPU 에서는 소프트웨어 렌더링을 쓴다
(3D 가속을 켠 VM 에서 GPU 를 쓰려면 `TOPOLOGY_GPU=1 ./vmware.sh`).

## 두 가지 뷰 (작업 표시줄 또는 Tab 으로 전환)

### ◈ 양자 뉴런 블록 — 본 화면 (Quantum Neuron Block Computing)

**블록 = 기능을 맡은 단자(모듈).** 블록들을 호환되는 단자끼리 조립해 시스템을 구축한다.
**No Base = 초기 상태**: Topology 자체의 시스템 구조가 하나의 **결정체**로 조립된 채 시작하고, 거기서 블록을 더하거나 다시 이어 키운다.
블록은 육각기둥 결정 셀이고, 선으로 잇지 않고 서로 면을 맞대고 맞물린다. 이어진 블록일수록 이웃 칸에 오고,
연결은 두 셀 사이 접합면이 신호 색으로 빛나는 것으로 보인다. 단자는 셀 윗면의 돌기다.

**차원 사양** (화면 위쪽에서 선택, 블록마다가 아니라 결정 전체에 적용 — [src/crystal.js](src/crystal.js))

| 차원 | 결정 |
| --- | --- |
| 4D 초입방 결정 | 컴퓨터 화면이 보여 줄 수 있는 가장 높은 차원. 넷째 축 w 를 두 칸 더한 격자를 비스듬히 투영하고, xw 평면에서 흔들린다 |
| 3D 입체 결정 | 셀이 벌집 층으로 쌓여 위아래·옆으로 맞물린다 (기본) |
| 2D 평면 결정 | 셀이 한 평면의 벌집으로 맞물린다 |
| 1D 선 결정 | 셀이 신호 순서대로 한 줄로 맞붙는다 |
| 0D 점 결정 | 모든 셀이 Topology 를 중심으로 응축된 결정 씨앗 |
게이트를 직접 설계하지 않는다. 각 처리 블록 안에 양자 뉴런이 하나씩 들어 있고, 사용자는 모듈을 조립한다.

| 묶음 | 블록 | 단자 (입력 → 출력) | 실제 환경 |
| --- | --- | --- | --- |
| 환경 | 데이터 | — → 데이터 | 고른 실제 폴더의 항목 수 |
| 환경 | 전화번호 · 계정 | — → 식별 | 이 컴퓨터의 계정 |
| 환경 | WIFI | — → 연결 | 지금 Wi-Fi 신호 세기 |
| 네트워크 | VPN | 연결, 데이터? → 연결 | VPN 인터페이스가 켜져 있는지 |
| 네트워크 | Network | 연결, 식별?, 데이터? → 연결 | |
| 네트워크 | 빅데이터 | 연결 → 데이터 | |
| 양자 · 처리 | QE 코어 | 데이터 → 양자 | |
| 양자 · 처리 | Instrument | 양자, 식별? → 명령 | |
| 양자 · 처리 | AI | 명령, 데이터? → 토큰 | |
| 양자 · 처리 | Graphic | 토큰 → 화면 | |
| 화면 | Topology | 화면, 명령? → — | 결과가 데스크톱 QE 시스템 창 · 작업 표시줄로 |

(`?` 는 비워 둬도 되는 단자)

- **호환** — 같은 신호 종류(같은 색) 단자끼리만 이어진다. 양자 신호는 복제할 수 없으므로 양자 출력은 한 곳에만 이어진다.
- **계산** — 조립이나 환경 값이 바뀔 때마다 시스템 전체를 신호 순서대로 계산한다. 양자 뉴런은 입력 세기를 큐비트 회전으로 싣고
  제어 회전으로 출력 큐비트를 움직여 1 이 될 확률을 낸다([src/blocks.js](src/blocks.js), [src/quantum.js](src/quantum.js)).
- **저장** — 조립한 시스템은 `~/.config/qe-analog-topology/program.json` 에 저장되어 다음에 이어서 쌓는다.

| 입력 | 동작 |
| --- | --- |
| 팔레트 클릭 · 판 위로 끌어다 놓기 | 블록 꺼내기 (결정의 빈 격자점에 맞물린다) |
| 4D · 3D · 2D · 1D · 0D | 결정 차원 사양 |
| 단자(윗면 돌기) 드래그 | 잇기 (이을 수 있는 단자만 빛난다) |
| 왼쪽 드래그 / 오른쪽 드래그 | 회전 / 이동 |
| 스크롤 | 다가가기 · 물러나기 |
| 클릭 · Delete | 셀·접합 선택(오른쪽 패널, 접합 끊기) · 지우기 |
| ↺ 초기 구조로 (No Base) | 결정체 초기 구조로 되돌리기 |

선택한 블록의 패널에서 Topology 환경으로 바로 간다: 데이터 → 폴더 층, WIFI·VPN·Network → 네트워크 창,
Instrument → 터미널, Topology → QE 시스템 창, 개념에 접목된 폴더.

### ▣ 데스크톱 — 깊이로 펼친 Digital OS

평소 2D 데스크톱과 같은 화면이 깊이 방향과 상하좌우로 이어진다.

- **스크롤** — 깊이(앞: 창 층 · 가운데: 바탕화면 · 뒤: 폴더 층). 멈추면 가장 가까운 층에 맞춰져 평소 화면 그대로 보인다.
- **마우스 끌기 · 화살표** — 한 층의 내용이 넘치면 페이지가 바둑판처럼 펼쳐진다. 빈 곳을 끌면 화면이 손을 따라오고,
  놓으면 가까운 페이지에 맞춰진다(1/5 이상 끌면 그 방향 다음 페이지).
- 폴더 클릭 = 뒤에 다음 층, 더블클릭 = 들어가기 / 파일 더블클릭 = 기본 앱. 폴더 탐색기 창은 없다.
- 바탕화면 아이콘: 양자 뉴런 블록, QE 시스템, 홈, 터미널.

## 구조

- [run.sh](run.sh), [server/server.js](server/server.js) — 로컬 서버(정적 파일 + 토큰 보호 API)
- [vmware.sh](vmware.sh), [app/main.js](app/main.js), [app/preload.js](app/preload.js) — Electron 전체 화면 셸
- [app/os-api.js](app/os-api.js) — 실제 OS 연결(파일, 앱, nmcli, 시스템 정보). 두 실행 방식이 함께 쓴다
- [src/bridge.js](src/bridge.js) — 화면 쪽 API (Electron 이면 preload, 아니면 토큰으로 서버 호출)
- [src/core.js](src/core.js) — 렌더러와 뷰 전환
- [src/diagram.js](src/diagram.js) — 양자 뉴런 블록 3D 조립판: 팔레트, 블록·단자·연결, 정보 패널, 마우스 조작
- [src/blocks.js](src/blocks.js) — 블록(기능 모듈) 정의, 호환 규칙, 시스템 계산(양자 뉴런)
- [src/crystal.js](src/crystal.js) — 결정 격자: 차원 사양(4D~0D)별 격자점, 셀 배치, 4D 투영
- [src/quantum.js](src/quantum.js) — 상태 벡터 시뮬레이터(H, Rx, Ry, CX, CRy, 블로흐 벡터)
- [src/desktop.js](src/desktop.js) — 데스크톱 뷰: 창 층 · 바탕화면 · 폴더 층, 스크롤 깊이 이동, 마우스로 상하좌우 페이지
- [src/taskbar.js](src/taskbar.js), [src/apps.js](src/apps.js) — 작업 표시줄·시작 메뉴, 내장 앱(터미널, 시스템, 네트워크, QE 시스템)
- [src/topology.config.js](src/topology.config.js) — 개념, 폴더 접목(ANCHORS), 조작 설정
